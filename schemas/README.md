# APP Schemas

JSON Schema definitions for Agent Presentation Protocol (APP) messages and data structures.

- `agent-card.schema.json` — Agent Card declaration format (includes `initiation` capability and `initiation_profile`; see SPEC.md §13)
- `messages.schema.json` — Complete JSON Schema definitions for all 27 protocol message types (see SPEC.md §4, §12.3, §14.4)
- `presence_state.json` — PresenceState broadcast shape (see SPEC.md §12)

These schemas can be used for validation in SDK implementations.
